# ToDo App

Простий застосунок для списку завдань. Робив для практики: фронт на чистому JS + простий сервер на Node.js.

## Що вміє

* Додавати завдання
* Відзначати як виконані
* Видаляти завдання
* Все працює через API

## Структура проєкту

```text
├── node_modules
├── private
│   ├── Db.js        — робота з даними
│   └── Routes.js    — маршрути API
├── public
│   ├── index.html   — сторінка
│   ├── script.js    — логіка на фронті
│   └── style.css    — стилі
├── package.json
├── package-lock.json
├── README.md
├── server.js        — сервер
└── tasks.json       — самі завдання

```

## Як запустити

```bash
# перейти в папку проєкту
cd ВАШЕ МІСЦЕ РОЗТАШУВАННЯ ФАЙЛУ

# встановити залежності
npm install

# запустити сервер
node server.js

```

Після цього відкрити в браузері:
http://localhost:3000
